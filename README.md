# Emil Reynolds — Executive Portfolio

Responsive, dependency-free static portfolio for executive recruiting, consulting, and technology products.

**Repository:** https://github.com/emilreynolds-blip/Emil-Reynolds-Portfolio

**Expected GitHub Pages URL after enabling Pages:** https://emilreynolds-blip.github.io/Emil-Reynolds-Portfolio/

## Turn on hosting (one-time)

1. Open **Settings → Pages** in this repository: https://github.com/emilreynolds-blip/Emil-Reynolds-Portfolio/settings/pages
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main**, folder **/(root)**, then **Save**.
4. Wait for deployment status to show success, then open the Pages URL above.

Note: Since this is a project repository (not the special `emilreynolds-blip.github.io` repository), the site lives at the subpath `/Emil-Reynolds-Portfolio/`.

## Update content safely

- `index.html` — text, sections, project information and metadata.
- `styles.css` — responsive design and brand colors.
- `script.js` — mobile menu, project filtering, footer year, public contact details.
- `assets/favicon.svg` — brand icon.
- `assets/social-preview.svg` — social artwork.
- `.nojekyll` — bypasses Jekyll processing.

To activate the contact buttons, edit `SITE_CONFIG.email` and `SITE_CONFIG.linkedin` at the top of `script.js`. They are blank for privacy. Add only contact information intended to be **public**.

## Publishing / security review

Before advertising this website publicly:
- [ ] Review the wording of all former employers, military service, consulting roles, and technology products.
- [ ] Verify rights to describe patents, Puca, DIB-X, Banzai, EW/RF work, and related intellectual property.
- [ ] Do not share proprietary, classified, controlled, sensitive customer or export-restricted details.
- [ ] Add a publicly approved résumé and headshot if desired.
- [ ] Enter a public email and LinkedIn URL only with approval.
- [ ] Test on a phone and laptop.

The site makes no commitment to an external analytics service or paid vendor. Specific dollar results and patent identifiers are intentionally left out pending verification.
